# 期货公司日研报下载器

一个 **本地可视化工具**：在浏览器面板里勾选要下载的期货公司、选择保存目录与日期，一键抓取各期货公司官网当日（最近一期）的期货日研报，保存为 PDF / DOCX。

后端为 Python(Flask)，前端为精美 HTML 面板，逻辑源自微信公众号《公歧研究：商品日研投获取.py》。

![界面预览](docs/screenshot.png)

## ✨ 功能特性

- 🖱️ **勾选 + 全选**：12 家期货公司卡片式勾选，支持「全选 / 清空」，实时显示已选数量。
- 📁 **选择保存目录**：点「浏览」弹出系统原生文件夹选择框，也支持直接输入路径，可一键「打开」目录。
- 📅 **研报日期**：默认当天，可指定任意日期（抓取各站“当日/最近一期”）。
- ⚡ **实时进度**：逐家公司显示成功 / 失败、文件大小与保存路径。
- 🌓 **深色现代 UI**：渐变主视觉、卡片布局、进度条与结果表格。
- 🚫 **互不影响**：个别公司失败不影响其余公司下载。

## 🚀 快速开始（从源码运行）

### 1. 安装依赖

需要 **Python 3.9+**。在项目目录执行：

```bash
pip install -r requirements.txt
python -m playwright install chromium   # 中原、华联、瑞达三家需要真实浏览器
```

### 2. 启动

```bash
python app.py
```

浏览器打开 **http://127.0.0.1:8899** 即可使用。

> 也可双击项目内的 `启动.bat`（Windows）。

### 3. 使用步骤

1. **选择期货公司**：勾选要下载的公司卡片（可点「全选 / 清空」）。
2. **研报日期**：默认当天；也可指定某一天。
3. **保存目录**：点「浏览」弹出系统文件夹选择框，或直接输入路径。
4. 点 **「开始下载」**，面板实时显示每家公司进度与结果。

下载内容保存到所选目录下的 **「期货日研投+日期」** 子文件夹，每家一份文件，命名「公司名+日期」。

## 📦 打包为 Windows exe

在项目目录执行：

```bash
pip install pyinstaller
pyinstaller futures_daily_report.spec
```

生成的可执行文件位于 `dist\` 目录。exe 已内置全部依赖（含 Playwright 驱动与 chromium），可直接分发给其他 Windows 用户，双击即用。

> 构建说明详见 [docs/BUILD.md](docs/BUILD.md)。

## ❓ 常见问题

- **中原 / 华联 / 瑞达显示 “Executable doesn't exist”**：说明当前 Python 的 playwright 缺 chromium 内核。执行 `python -m playwright install chromium`。程序启动时也会自动检测并提示。
- **国信期货显示“需登录/暂不支持”**：国信官网研报入口为前端 JS 且需会员登录，点击条目无响应，当前版本无法自动下载，请手动访问其官网。
- **中原 / 华联 / 瑞达下载失败**：多为站点反爬或当天未更新研报，重试或改天再试。
- **个别公司失败不影响其他公司**：面板逐家独立执行并汇总结果。
- **证书告警**：工具对部分证书链不完整的期货公司站点关闭了证书校验，属预期行为。
- **端口占用**：若 8899 端口被占用，可设置环境变量换端口：`set PORT=9000` 后重新启动。
