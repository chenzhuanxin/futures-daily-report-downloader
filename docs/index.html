开源 · 本地运行 · 数据来自各期货公司官网公开页面

期货公司日研报下载器

在精美面板里勾选 12 家期货公司、选择保存目录与日期，一键抓取当日（最近一期）期货日研报，保存为 PDF / DOCX。

⬇ 下载 Windows 版 exe GitHub 仓库

★功能特性

  • 勾选 + 全选：12 家期货公司卡片式勾选，支持「全选 / 清空」，实时显示已选数量。
  • 选择保存目录：点「浏览」弹出系统原生文件夹选择框，也支持直接输入路径，可一键「打开」目录。
  • 研报日期：默认当天，可指定任意日期（抓取各站“当日/最近一期”）。
  • 实时进度：逐家公司显示成功 / 失败、文件大小与保存路径。
  • 深色现代 UI：渐变主视觉、卡片布局、进度条与结果表格。
  • 互不影响：个别公司失败不影响其余公司下载。

⏱使用步骤

选择期货公司：勾选要下载的公司卡片（可点「全选 / 清空」）。
研报日期：默认当天；也可指定某一天。
保存目录：点「浏览」弹出系统文件夹选择框，或直接输入路径。
开始下载：点「开始下载」，面板实时显示每家公司进度与结果。

下载内容保存到所选目录下的「期货日研投+日期」子文件夹，每家一份，命名「公司名+日期」。

▶从源码运行

pip install -r requirements.txt
python -m playwright install chromium
python app.py

浏览器打开 http://127.0.0.1:8899 即可使用（Windows 也可双击 启动.bat）。

📌 中原期货 / 华联期货 / 瑞达期货依赖 Playwright 的 chromium 内核；exe 版已内置，源码运行需执行上面的 playwright install chromium。国信期货入口需会员登录，暂无法自动下载。
